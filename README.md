# BertotiMetodologiaReal


Definição

O projeto FATEC-API-3-SEMESTRE é uma aplicação web desenvolvida para capturar, armazenar e consultar notícias estratégicas vindas de portais de notícias e APIs públicas. A ideia principal do sistema é criar um histórico de dados que possa ser usado futuramente para análises com inteligência artificial.

O sistema permite o cadastro de portais de notícias, APIs, tags e jornalistas, além de possuir funcionalidades de captura automatizada de dados por meio de web scraping. Também possui telas de consulta com filtros, permitindo buscar notícias e APIs cadastradas de forma mais organizada.

Tecnologias

O projeto foi desenvolvido usando uma arquitetura web com backend em Spring Boot e frontend em Vue 3. O repositório também utiliza Docker para padronizar o ambiente de desenvolvimento, Node.js/NPM para gerenciamento do frontend, NX para organização de tarefas, e PostgreSQL como banco de dados.

As principais linguagens presentes no repositório são Java, Vue, HTML, CSS, Dockerfile e TypeScript. No GitHub, o repositório aparece principalmente dividido entre Java no backend e Vue no frontend.

Também foram usados recursos como Hibernate para mapeamento objeto-relacional e Flyway para controle de migrações do banco de dados.
