# FATEC-API-3-SEMESTRE

## Definição

O projeto **FATEC-API-3-SEMESTRE** é uma aplicação web desenvolvida para capturar, armazenar e consultar notícias estratégicas vindas de portais de notícias e APIs públicas.

A ideia principal do sistema é criar um histórico de dados que possa ser usado futuramente para análises com inteligência artificial.

O sistema permite o cadastro de portais de notícias, APIs, tags e jornalistas, além de possuir funcionalidades de captura automatizada de dados por meio de web scraping. Também possui telas de consulta com filtros, permitindo buscar notícias e APIs cadastradas de forma mais organizada.

## Tecnologias

O projeto foi desenvolvido usando uma arquitetura web com **backend em Spring Boot** e **frontend em Vue 3**.

As principais tecnologias utilizadas no projeto foram:

- Java
- Spring Boot
- Vue 3
- TypeScript
- HTML
- CSS
- PostgreSQL
- Docker
- Node.js
- NPM
- Hibernate
- Flyway
- GitHub

O **Spring Boot** foi utilizado para desenvolver a API backend, responsável pelas regras de negócio, controllers, services, repositories e comunicação com o banco de dados.

O **Vue 3** foi utilizado no frontend para criação das telas e componentes da aplicação.

O **PostgreSQL** foi utilizado como banco de dados da aplicação, enquanto o **Docker** ajudou a padronizar o ambiente de desenvolvimento.

Também foram utilizados **Hibernate** para o mapeamento objeto-relacional e **Flyway** para o controle das migrações do banco de dados.
